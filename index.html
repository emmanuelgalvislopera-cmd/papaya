Ciclos

los ciclos nos permite repetir acciones hasta un limites puesto
-ciclo while:El ciclo while es un ciclo repetitivo basado en los resultados de una expresión lógica
-ciclo for:El ciclo for es una estructura de control en programación que permite repetir un bloque de código un número determinado de veces

switch case

La estructura switch case es una estructura de control condicional que evalúa una sola variable y ejecuta diferentes bloques de código según el valor específico que tome esa variable [1, 2].

condicionales

Los condicionales son estructuras de control que permiten a un programa tomar decisiones y ejecutar diferentes bloques de código según si una condición lógica resulta ser verdadera o falsa
